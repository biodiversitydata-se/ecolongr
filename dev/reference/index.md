# Package index

## Alpha diversity

Richness, diversity indices and rarefaction of each sample.

- [`el_diversity()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_diversity.md)
  [`el_specnumber()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_diversity.md)
  : Alpha diversity of each sample
- [`el_drarefy()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_drarefy.md)
  [`el_rarefy()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_drarefy.md)
  : Expected presence and richness at a common depth
- [`el_rrarefy()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_rrarefy.md)
  : Rarefy samples to a common depth
- [`el_frequency_counts()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_frequency_counts.md)
  : Frequencies of frequencies

## Beta diversity

Standardisation and dissimilarities between samples.

- [`el_decostand()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_decostand.md)
  : Standardise a long table within samples
- [`el_vegdist()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_vegdist.md)
  : Dissimilarity from a long table

## Ordination

Principal components of the table, in the `rda` class of vegan.

- [`el_rda()`](https://biodiversitydata-se.github.io/ecolongr/dev/reference/el_rda.md)
  : Principal components of a long table
