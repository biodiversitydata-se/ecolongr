# ecolongr: Community Ecology Analyses on Long Tables

Distances, transformations and ordination for community data kept as
long tables without zeros, computed lazily with 'duckplyr' so that the
full taxa by samples matrix is never held in memory. Results are tested
against 'vegan'.
